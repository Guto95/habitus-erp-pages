1. 사용하는 Google 권한

이 앱은 https://www.googleapis.com/auth/calendar.app.created 권한만 요청합니다. 이 권한으로는 앱이 직접 만든 캘린더 「아비투스 수업」에만 접근할 수 있으며, 사용자의 다른 캘린더와 일정은 읽거나 바꿀 수 없습니다.

2. Google 사용자 데이터의 이용

  • 앱은 「아비투스 수업」 캘린더에 수업 일정을 만들고, 수정하고, 삭제합니다.
  • 같은 캘린더의 일정 목록은 이미 옮겨 적은 일정과 비교하는 데에만 읽습니다.
  • Google 사용자 데이터를 제3자에게 판매하거나 전송하지 않으며, 광고나 다른 목적에 쓰지 않습니다.

3. 저장

인증 정보는 운영자의 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다. 앱 사용을 중단하면 Google 계정 권한 페이지에서 언제든 접근 권한을 해제할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
